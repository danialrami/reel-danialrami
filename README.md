# Sound Design Reel Website

Personal portfolio website showcasing my sound design work. Built with static HTML/CSS following the Echo Bridge Manual design system.

## Overview

A minimalist, retro-styled single-page website featuring a video reel player. Uses the same design aesthetic as the Echo Bridge Manual — a dark theme with accent colors and flat UI elements.

## Tech Stack

- Static HTML5, CSS3, Vanilla JavaScript
- Self-hosted MP4 video
- Host Grotesk + Public Sans typography
- No frameworks or build tools

## Quick Start

1. Open `index.html` in a browser
2. Or serve locally: `npx serve .` or `python -m http.server 8000`

## Deployment

Deploy to GitHub Pages, Netlify, or Vercel. The site is a static HTML file that can be hosted anywhere.
